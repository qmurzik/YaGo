# YaGo Tweaks

Модуль LSPosed для кастомизации **Яндекс Go** (`ru.yandex.taxi`): блокировка рекламы,
скрытие ненужных элементов интерфейса, инспектор элементов.

Модуль **не привязан к именам классов приложения**: все хуки ставятся только на классы
Android SDK (`Activity`, `View`, `Window`, `WindowManagerGlobal`, `InetAddress`, `WebView`),
а элементы ищутся по признакам, которые видны на экране (текст, описание, имя ресурса).
Поэтому он не должен ломаться при обновлениях Яндекс Go и смене обфускации. Рассчитан на 5.98.0 и новее,
LSPosed API 93+.

## Возможности

| Функция | Как работает |
|---|---|
| **Скрытие любого элемента** | Пикер прямо в Яндекс Go: тап по элементу → «Шире/Уже» → «Скрыть». Правило составляется автоматически |
| Блокировка рекламных сетей | Хук `InetAddress.getAllByName/getByName` и `WebView.loadUrl`: запросы к рекламным доменам получают `UnknownHostException` |
| Блокировка аналитики (выкл. по умолчанию) | То же для AppMetrica, Firebase, AppsFlyer и т.п. |
| Скрытие рекламных блоков | Элементы рекламных SDK и контейнеры с id вида `ad_*`, `adview`, `native_ad`… |
| Скрытие карточек «Реклама» | Карточка в ленте, внутри которой есть надпись «Реклама», «Ad», «Sponsored» |
| Свои правила | Редактор правил в настройках модуля, импорт/экспорт через буфер обмена |
| Разрешить скриншоты | Снимает `FLAG_SECURE` |
| Режим отладки | Дерево элементов каждого экрана в logcat (тег `YaGo`) |

Скрытый элемент получает `GONE` и остаётся скрытым, даже если приложение пытается показать его снова.
Ячейка списка, переиспользованная под другой контент, автоматически возвращается.

## Установка

1. Скачайте APK из [Actions](../../actions) (артефакт `YaGoTweaks-apk`) или соберите сами: `./gradlew assembleRelease`.
2. Установите, включите модуль в LSPosed, в области действия отметьте **Яндекс Go**.
3. Принудительно остановите Яндекс Go и откройте заново.

## Как скрыть элемент

1. В Яндекс Go удерживайте **два пальца** на экране ~1 секунду (или включите в настройках
   плавающую кнопку ✂ и нажмите её).
2. Нажмите на элемент — он подсветится синей рамкой (пунктиром показан его контейнер).
   Прокручивать экран в этом режиме можно как обычно.
3. **⬆ Шире / ⬇ Уже** — выбор уровня: например, только плитка «Лавка» или весь блок сервисов.
4. **Скрыть элемент.** Сразу после скрытия есть «Отменить».
5. **Скрытые** — список всего скрытого: выключить, удалить, скопировать.

Правило составляется автоматически: модуль перебирает признаки элемента и его содержимого
(id, описание, текст) и выбирает тот, что на текущем экране находит **только этот** элемент.
Числа обобщаются (`У вас долг 113₽` → `У вас долг \d…₽`), чтобы правило не ломалось при смене суммы
или времени. Нажатие на строку с правилом (или долгое нажатие на «Скрыть») — другие варианты.

### Формат правил (для ручного редактирования)

```
тип:регулярное_выражение [^N]

text:^\s*Самокаты\s*$ ^1     # контейнер (1 уровень выше) текста «Самокаты»
id:^promo_banner$             # по имени ресурса id
desc:^Истории$                # по описанию для TalkBack
class:StoriesView$            # по имени класса (может меняться между версиями)
```

Правила, созданные в Яндекс Go, хранятся в самом приложении (Android не даёт приложению
передать их модулю). Чтобы перенести их в настройки модуля: «Скрытые» → «Копировать»,
затем в модуле «Свои правила» → «Импорт».

## Ограничения

- Элементы, нарисованные Jetpack Compose, для Android — одно большое View: их нельзя скрыть по отдельности,
  только целиком.
- Реклама, которую приложение получает со своих же серверов (промо-баннеры в API Яндекса),
  доменной блокировкой не отрезается — для неё используйте правила скрытия.
- Сетевые запросы из нативного кода (Cronet/NDK) хуком `InetAddress` не перехватываются.
