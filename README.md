# YaGo Tweaks

Модуль LSPosed для кастомизации **Яндекс Go** (`ru.yandex.taxi`): блокировка рекламы,
скрытие ненужных элементов интерфейса, инспектор элементов.

Модуль **не привязан к именам классов приложения**: все хуки ставятся только на классы
Android SDK (`Activity`, `View`, `Window`, `WindowManagerGlobal`, `InetAddress`, `WebView`),
а элементы ищутся по признакам, которые видны на экране (текст, описание, имя ресурса).
Поэтому он не должен ломаться при обновлениях Яндекс Go и смене обфускации. Рассчитан на 5.98.0 и новее,
LSPosed API 93+.

## Возможности

| Функция | Как работает |
|---|---|
| Блокировка рекламных доменов | Хук `InetAddress.getAllByName/getByName` и `WebView.loadUrl`: запросы к рекламным сетям получают `UnknownHostException` |
| Блокировка аналитики (выкл. по умолчанию) | То же для AppMetrica, Firebase, AppsFlyer и т.п. |
| Скрытие рекламных элементов | Элементы рекламных SDK и контейнеры с id вида `ad_*`, `adview`, `native_ad`… |
| Скрытие карточек «Реклама» | Карточка списка/ленты, внутри которой есть надпись «Реклама», «Ad», «Sponsored» |
| Свои правила скрытия | По id, тексту, contentDescription или классу; с подъёмом на N родителей |
| Инспектор | Жест в самом приложении: выбрать элемент и скрыть его одним нажатием |
| Разрешить скриншоты | Снимает `FLAG_SECURE` |
| Режим отладки | Пишет дерево элементов каждого экрана в logcat (тег `YaGo`) |

Скрытый элемент получает `GONE` и остаётся скрытым, даже если приложение пытается показать его снова.
Если ячейка списка переиспользована под другой контент и больше не подходит под правило, она
автоматически возвращается.

## Установка

1. Скачайте APK из [Actions](../../actions) (артефакт `YaGoTweaks-apk`) или соберите сами: `./gradlew assembleRelease`.
2. Установите, включите модуль в LSPosed, в области действия отметьте **Яндекс Go**.
3. Принудительно остановите Яндекс Go и откройте заново.

## Как скрыть элемент

**Через инспектор (проще всего):** в Яндекс Go положите два пальца на нужный элемент и держите
неподвижно ~1,5 с. Появится список элементов под первым пальцем — сверху самый вложенный,
ниже его родители (`↑1`, `↑2`…). Выберите уровень (он подсветится красным), затем правило и нажмите
**Скрыть**. Правило сохраняется внутри Яндекс Go; кнопка **Копировать** позволяет перенести его
в настройки модуля. Список локальных правил — первый пункт меню инспектора.

**Вручную:** в настройках модуля, по одному правилу в строке:

```
# тип:регулярное_выражение [^N]
id:^promo_banner$            # по имени ресурса id
text:^Реклама$ ^3            # по тексту; скрыть 3-го родителя найденного элемента
desc:^Истории$               # по contentDescription
class:StoriesView$           # по имени класса (может меняться между версиями)
```

Выражения — регулярные (Java), ищутся в строке, без учёта регистра.
Самые устойчивые к обновлениям правила — по **тексту** и **описанию**; правила по классу
в обфусцированном приложении могут перестать работать после обновления.

## Ограничения

- Элементы, нарисованные Jetpack Compose, для Android — одно большое View: их нельзя скрыть по отдельности,
  только целиком.
- Реклама, которую приложение получает со своих же серверов (промо-баннеры в API Яндекса),
  доменной блокировкой не отрезается — для неё используйте правила скрытия.
- Сетевые запросы из нативного кода (Cronet/NDK) хуком `InetAddress` не перехватываются.
